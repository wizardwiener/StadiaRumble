UMDF2 HID-минидрайвер для Windows 10/11 x64 и настольное приложение **Stadia Rumble Studio** для **Google Stadia Controller** (Bluetooth LE и USB). Определяет геймпад в играх как стандартный **Xbox Wireless Controller (XInput)** с полноценной вибрацией обоих моторов, автономными драйверными профилями (`0xE2`, `0xE3`) и телеметрией BLE в реальном времени (`0xE1`).

*Независимый open-source проект, не связанный с Google или Microsoft. Драйверная часть (`driver/`) основана на [`aisk/WinStadia`](https://github.com/aisk/WinStadia) под лицензией GNU **GPL-3.0** — см. [`LICENSE`](./LICENSE), [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md) и [`UPSTREAM_REVISION.txt`](./UPSTREAM_REVISION.txt).*

## Проверенные результаты и стабильность

Протестировано на реальном оборудовании под управлением **Windows 11 / 10 Pro 26H2 (Build 26300.9974)**, а также на сборках **26200 и 26220** по Bluetooth LE:

| Показатель | Зафиксированный результат |
| :--- | :--- |
| **Интервал BLE-соединения (ввод)** | `7,5 мс` (~133 Гц при непрерывном движении) |
| **Задержка подтверждения вибрации (BLE ACK)** | `16 мс` (`WriteLatencyMs`) |
| **Стресс-тест записи вибрации** | `1048 / 1048` успешных операций (`0` сбоев) |
| **Ошибки драйвера / GATT** | `0x00000000` (`DriverError` и `RumbleError`) |
| **Телеметрия заряда** | Проценты в реальном времени через Windows BLE GATT (`0x180F`) + `0xE1` |

## Возможности

### 1. UMDF2 HID-драйвер (`driver/`)
- **Работа по Bluetooth LE и USB:** подключает Stadia Controller как **Xbox Wireless Controller** (`VID_045E / PID_02FD`) через штатный `xinputhid` без изменения системных файлов и без режима Test Mode.
- **Выделенный поток вибрации с коалесингом:** очереди чтения ввода (`IOCTL_HID_READ_REPORT`) и записи вибрации через `bthserv` полностью разделены и не блокируют друг друга. Команда остановки `(0, 0)` имеет наивысший приоритет.
- **Feature Report `0xE1` (Телеметрия):** передаёт тип подключения, текущую нагрузку моторов, количество записей и сбоев, реальную задержку BLE ACK (`мс`), коды ошибок `NTSTATUS`, статус Turbo и сырой HID-отчёт (включая кнопки `Assistant` и `Capture`).
- **Feature Report `0xE2` (Профиль в реестре драйвера):**
  - Сила левого (`Strong`) и правого (`Weak`) вибромоторов (`0–100%`)
  - Мёртвые зоны стиков (`0–25%`) и триггеров (`0–20%`), режим Hair-Trigger (`50–100%`)
  - Обмен стиков (`Swap LS ↔ RS`) и инверсия осей `LY` / `RY`
  - Тайминги BLE (`IntervalMs`, `PostAckGapMs`, `MinDelta`) для защиты Bluetooth-адаптера от перегрузки
  - **Аппаратный Турбо-режим (`Assistant + кнопка`):** таймер `WdfTimer` прямо в драйвере (`5–25 Гц`, режим **Toggle** или **Hold**) для `A/B/X/Y/L1/R1/L2/R2/LS/RS` с сохранением в `0xE2`
- **Feature Report `0xE3` + нативные коллекции Keyboard (`0x05`) и Consumer (`0x06`):**
  - `winstadia.dll` добавляет нативные коллекции HID Keyboard (`UsagePage 0x01 / Usage 0x06`) и Consumer Control (`UsagePage 0x0C / Usage 0x01`) рядом с геймпадом Xbox (`Col01`).
  - Действия для `Assistant`, `Capture`, `Assistant + Крестовина` (громкость +/– и переключение треков с полным подавлением крестовины и её диагоналей в игре) и своей клавиши выполняются прямо в драйвере и сохраняются в PnP-реестре устройства (`StadiaMacroSettings`).
  - Мгновенная отправка макросов без задержек (`KeyboardChanged`/`ConsumerChanged` перед отчётами геймпада, восстановление быстрого двойного нажатия, `30 мс` импульс, чистое обнуление модификаторов при `D0Exit`) и точная синхронизация своей клавиши (`HidUsageToVk`).

### 2. Stadia Rumble Studio (`app/` + `app/web/`)
- **Полноценный веб-интерфейс прямо на рабочем столе:** запуск `StadiaRumble.bat` (или `StadiaRumble.exe`) открывает точную 1:1 студию **Stadia Rumble Studio** в отдельном окне приложения без панелей браузера — поверх локального нативного моста драйвера (`127.0.0.1`: XInput + `0xE1`/`0xE2`/`0xE3` + Windows BLE Battery + журналы Windows), с резервным запуском классического WinForms-окна по флагу `--classic`.
- **6 вкладок студии:** *Геймпад* (интерактивный монитор Stadia, выбор слота `#1–#4` и прямой тест моторов), *Мониторинг BLE* (живые графики задержки, RSSI и записей/сбоев), *Питание* (график разряда `0xE1` + Windows BLE Battery), *Макросы и Турбо* (автономные драйверные макросы `0xE3`, наглядный выбор **Своей клавиши** с захватом с клавиатуры, отменой по `Esc` и пресетами + аппаратный Turbo `5–25 Гц` `0xE2`), *Патч WebUSB / `0xE2`* (полная настройка вибромоторов, мёртвых зон, Hair-Trigger, инверсии/обмена стиков, BLE-таймингов и экспорт `.bin`/`.reg`) и *Дамп-анализатор* (сканер событий Windows WUDF/`bthserv` и анализатор `.txt`-логов).
- **Полный выход при закрытии `[X]` (0 фоновых процессов):** закрытие окна полностью завершает `StadiaRumble.exe`, так как и макросы (`0xE3`), и Turbo (`0xE2`) работают автономно внутри системного драйвера `winstadia.dll` даже после перезагрузки ПК.
- **4 языка интерфейса (`УКР / ENG / DEU / РУС`):** мгновенное переключение языка (**Українська**, **English**, **Deutsch**, **Русский**) с сохранением в реестре Windows.
- **Сборка без SDK:** `StadiaRumble.bat` автоматически компилирует `StadiaRumble.exe` встроенным компилятором Windows (`.NET Framework 4.x`) при изменении исходного кода (проверка по SHA-256) и устанавливает фирменную иконку Stadia.

## Требования

- **ОС:** Windows 10/11 **x64** (Build 22000 или новее; проверено вплоть до сборки **26300**).
- **Контроллер:** Google Stadia Controller в **режиме Bluetooth LE** или подключённый по кабелю USB-C.
- **Права:** права администратора (UAC) требуются только на этапе установки или удаления драйвера.
- **Дополнительное ПО:** **заранее ничего устанавливать не нужно.** Visual Studio и WDK не требуются — `driver/build.ps1` автоматически скачивает официальные портативные файлы Microsoft (MSVC + SDK + WDK) во временные каталоги, которые `install.bat` очищает сразу после установки.

## Быстрый старт (для пользователей)

1. Скачайте актуальный архив (`StadiaRumble-1.0.15-win-x64.zip`) со страницы [**GitHub Releases**](https://github.com/wizardwiener/StadiaRumble/releases) и распакуйте его в любую папку.
2. Нажмите правой кнопкой на **`install.bat`** (или **`manage.bat`**) → **Запуск от имени администратора**.
   - Скрипт при необходимости соберёт актуальный `winstadia.dll`, создаст одноразовый локальный сертификат (и сразу удалит закрытый ключ после подписания), установит драйвер через `pnputil` и скомпилирует `StadiaRumble.exe`.
3. Подключите **Google Stadia Controller** по Bluetooth LE или USB.
4. Запустите **`StadiaRumble.bat`** для проверки вибрации, просмотра графиков BLE/аккумулятора и сохранения профилей `0xE2` / `0xE3` в драйвер — после настройки окно можно полностью закрыть `[X]`.

Чтобы полностью удалить драйвер и вернуть стандартный HID-драйвер Windows, запустите **`uninstall.bat`** от имени администратора (или `.\driver\install.ps1 -Uninstall`).

## Сборка из исходного кода (для разработчиков)

```powershell
git clone https://github.com/wizardwiener/StadiaRumble.git
cd StadiaRumble

# 1. Собрать UMDF2-драйвер (результат в driver\out\pkg)
Set-ExecutionPolicy -Scope Process Bypass
.\driver\build.ps1

# 2. Установить драйвер (запросит UAC)
.\driver\install.ps1

# 3. Проверить состояние драйвера в консоли
.\driver\status.ps1

# 4. Собрать и запустить Stadia Rumble Studio
.\StadiaRumble.bat
```

## Архитектурные особенности и известные ограничения

- **Внутренний WinRT GATT интерфейс (`private-gatt.cpp`):** стандартный драйвер Windows `HidOverGatt` не принимает команды вибрации (`0xC0070057`), так как характеристика вывода контроллера Stadia не имеет флага `Write Without Response`. Драйвер обходит это ограничение, взаимодействуя с `bthserv` через тот же интерфейс `GattClientDevice`, которым пользуется сама Windows. Проверено на сборках **26200**, **26220** и **26300**. Будущие крупные обновления стека Bluetooth в Windows теоретически могут изменить эти слоты vtable.
- **Локальная подпись пакета:** Windows требует цифровой подписи для установки драйверов; `install.ps1` создаёт локальный сертификат только для вашего ПК и безвозвратно удаляет закрытый ключ сразу после подписания `winstadia.cat`.
- **Событийная передача по BLE:** контроллер Stadia в режиме Bluetooth отправляет HID-отчёт только при изменении состояния кнопки или положения стика. При непрерывном движении стика частота обновлений соответствует интервалу BLE **7,5 мс (~133 Гц)**.

## Решение проблем

- **Контроллер не отображается в Studio:** убедитесь, что Bluetooth включён, переподключите геймпад, проверьте переключатель слота XInput (`#1–#4`) или выполните `.\driver\status.ps1`.
- **Предупреждение о недоступности `0xE2` или `0xE3`:** в хранилище драйверов Windows всё ещё активна устаревшая версия `winstadia.dll`. Запустите `install.bat` от имени администратора повторно, чтобы пересобрать и обновить пакет драйвера.
- **Нет вибрации в играх:** убедитесь, что ползунки силы моторов (`Strong/Weak %`) на вкладке **Моторы** выставлены выше `0%`, проверьте кнопку **Импульс 1.5с** в Studio и включите вибрацию в настройках самой игры.
