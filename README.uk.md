UMDF2 HID-мінідрайвер для Windows 10/11 x64 та настільна утиліта **Stadia Rumble Studio** для **Google Stadia Controller** (Bluetooth LE та USB). Емулює геймпад як стандартний **Xbox Wireless Controller (XInput)** із повноцінною вібрацією обох моторів, автономними драйверними профілями (`0xE2`, `0xE3`) та телеметрією BLE у реальному часі (`0xE1`).

*Це незалежний open-source проєкт, не пов'язаний із Google чи Microsoft. Драйверна частина (`driver/`) заснована на [`aisk/WinStadia`](https://github.com/aisk/WinStadia) під ліцензією GNU **GPL-3.0** — див. [`LICENSE`](./LICENSE), [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md) та [`UPSTREAM_REVISION.txt`](./UPSTREAM_REVISION.txt).*

## Перевірені результати та стабільність

Протестовано на реальному обладнанні під керуванням **Windows 11 / 10 Pro 26H2 (Build 26300.9974)**, а також на збірках **26200 і 26220** через Bluetooth LE:

| Показник | Зафіксований результат |
| :--- | :--- |
| **Інтервал BLE-з'єднання (введення)** | `7,5 мс` (~133 Гц при безперервному русі) |
| **Затримка підтвердження вібрації (BLE ACK)** | `16 мс` (`WriteLatencyMs`) |
| **Стрес-тест запису вібрації** | `1048 / 1048` успішних операцій (`0` збоїв) |
| **Помилки драйвера / GATT** | `0x00000000` (`DriverError` і `RumbleError`) |
| **Телеметрія заряду** | Відсотки в реальному часі через Windows BLE GATT (`0x180F`) + `0xE1` |

## Можливості

### 1. UMDF2 HID-драйвер (`driver/`)
- **Робота через Bluetooth LE та USB:** підключає Stadia Controller як **Xbox Wireless Controller** (`VID_045E / PID_02FD`) через штатний `xinputhid` без модифікації системних файлів і без режиму Test Mode.
- **Окремий потік вібрації з коалесингом:** черги читання введення (`IOCTL_HID_READ_REPORT`) та запису вібрації через `bthserv` повністю розділені й не блокують одна одну. Команда зупинки `(0, 0)` має найвищий пріоритет.
- **Feature Report `0xE1` (Телеметрія):** передає тип підключення, поточне навантаження моторів, кількість записів і збоїв, реальну затримку BLE ACK (`мс`), коди помилок `NTSTATUS`, стан Turbo та сирий HID-звіт (разом із кнопками `Assistant` і `Capture`).
- **Feature Report `0xE2` (Профіль у реєстрі драйвера):**
  - Сила лівого (`Strong`) та правого (`Weak`) вібромоторів (`0–100%`)
  - Мертві зони стіків (`0–25%`) і тригерів (`0–20%`), режим Hair-Trigger (`50–100%`)
  - Обмін стіків (`Swap LS ↔ RS`) та інверсія осей `LY` / `RY`
  - Таймінги BLE (`IntervalMs`, `PostAckGapMs`, `MinDelta`) для захисту Bluetooth-адаптера від перевантаження
  - **Апаратний Турбо-режим (`Assistant + кнопка`):** таймер `WdfTimer` у самому драйвері (`5–25 Гц`, режим **Toggle** або **Hold**) для `A/B/X/Y/L1/R1/L2/R2/LS/RS` зі збереженням у `0xE2`
- **Feature Report `0xE3` + нативні колекції Keyboard (`0x05`) і Consumer (`0x06`):**
  - `winstadia.dll` додає нативні колекції HID Keyboard (`UsagePage 0x01 / Usage 0x06`) та Consumer Control (`UsagePage 0x0C / Usage 0x01`) поруч із геймпадом Xbox (`Col01`).
  - Дії для `Assistant`, `Capture`, `Assistant + Хрестовина` (гучність +/– і перемикання треків із повним приглушенням хрестовини та її діагоналей у грі) і власної клавіші виконуються прямо в драйвері й зберігаються в PnP-реєстрі пристрою (`StadiaMacroSettings`).
  - Миттєве беззатримкове надсилання макросів (`KeyboardChanged`/`ConsumerChanged` перед звітами геймпада, відновлення швидкого подвійного натискання, `30 мс` імпульс, чисте скидання модифікаторів у `D0Exit`) і точна синхронізація власної клавіші (`HidUsageToVk`).

### 2. Stadia Rumble Studio (`app/` + `app/web/`)
- **Повноцінний веб-інтерфейс просто на робочому столі:** запуск `StadiaRumble.bat` (або `StadiaRumble.exe`) відкриває точну 1:1 студію **Stadia Rumble Studio** в окремому вікні програми без панелей браузера — поверх локального нативного моста драйвера (`127.0.0.1`: XInput + `0xE1`/`0xE2`/`0xE3` + Windows BLE Battery + журнали Windows), із запасним запуском класичного WinForms-вікна через параметр `--classic`.
- **6 вкладок студії:** *Геймпад* (інтерактивний монітор Stadia, вибір слота `#1–#4` і прямий тест моторів), *Моніторинг BLE* (живі графіки затримки, RSSI та записів/збоїв), *Живлення* (графік розряду `0xE1` + Windows BLE Battery), *Макроси і Турбо* (автономні драйверні макроси `0xE3`, інтуїтивний вибір **Власної клавіші** із захопленням із клавіатури, скасуванням через `Esc` і пресетами + апаратний Turbo `5–25 Гц` `0xE2`), *Патч WebUSB / `0xE2`* (повне налаштування вібромоторів, мертвих зон, Hair-Trigger, інверсії/обміну стіків, BLE-таймінгів та експорт `.bin`/`.reg`) і *Дамп-аналізатор* (сканер подій Windows WUDF/`bthserv` та аналізатор `.txt`-логів).
- **Повний вихід при закритті `[X]` (0 фонових процесів):** закриття вікна повністю завершує `StadiaRumble.exe`, адже і макроси (`0xE3`), і Turbo (`0xE2`) працюють автономно всередині системного драйвера `winstadia.dll` навіть після перезавантаження ПК.
- **4 мови інтерфейсу (`УКР / ENG / DEU / РУС`):** миттєве перемикання мови (**Українська**, **English**, **Deutsch**, **Русский**) зі збереженням у реєстрі Windows.
- **Збірка без SDK:** `StadiaRumble.bat` автоматично компілює `StadiaRumble.exe` вбудованим компілятором Windows (`.NET Framework 4.x`) за умови зміни коду (перевірка за SHA-256) та встановлює фірмову іконку Stadia.

## Вимоги

- **ОС:** Windows 10/11 **x64** (Build 22000 або новіша; перевірено включно зі збіркою **26300**).
- **Контролер:** Google Stadia Controller у **режимі Bluetooth LE** або підключений через USB-C.
- **Права:** права адміністратора (UAC) потрібні лише на етапі встановлення чи видалення драйвера.
- **Додаткове ПЗ:** **нічого заздалегідь встановлювати не потрібно.** Visual Studio та WDK не потрібні — `driver/build.ps1` автоматично завантажує офіційні портативні файли Microsoft (MSVC + SDK + WDK) у тимчасові каталоги, які `install.bat` очищає одразу після встановлення.

## Швидкий старт (для користувачів)

1. Завантажте останній архів (`StadiaRumble-1.0.15-win-x64.zip`) зі сторінки [**GitHub Releases**](https://github.com/wizardwiener/StadiaRumble/releases) і розпакуйте його в будь-яку папку.
2. Натисніть правою кнопкою на **`install.bat`** (або **`manage.bat`**) → **Запуск від імені адміністратора**.
   - Скрипт за потреби збере актуальний `winstadia.dll`, створить одноразовий локальний сертифікат (і одразу видалить приватний ключ після підписання), встановить драйвер через `pnputil` та скомпілює `StadiaRumble.exe`.
3. Підключіть **Google Stadia Controller** через Bluetooth LE або USB.
4. Запустіть **`StadiaRumble.bat`** для перевірки вібрації, перегляду графіків BLE/батареї та збереження профілів `0xE2` / `0xE3` у драйвер — після налаштування вікно можна повністю закрити `[X]`.

Щоб повністю видалити драйвер і повернути стандартний HID-драйвер Windows, запустіть **`uninstall.bat`** від імені адміністратора (або `.\driver\install.ps1 -Uninstall`).

## Збірка з вихідного коду (для розробників)

```powershell
git clone https://github.com/wizardwiener/StadiaRumble.git
cd StadiaRumble

# 1. Зібрати UMDF2-драйвер (результат у driver\out\pkg)
Set-ExecutionPolicy -Scope Process Bypass
.\driver\build.ps1

# 2. Встановити драйвер (запитає UAC)
.\driver\install.ps1

# 3. Перевірити стан драйвера у консолі
.\driver\status.ps1

# 4. Зібрати і запустити Stadia Rumble Studio
.\StadiaRumble.bat
```

## Архітектурні особливості та відомі обмеження

- **Внутрішній WinRT GATT інтерфейс (`private-gatt.cpp`):** стандартний драйвер Windows `HidOverGatt` не приймає команди вібрації (`0xC0070057`), оскільки характеристика виводу контролера Stadia не має прапорця `Write Without Response`. Драйвер обходить це обмеження через взаємодію з `bthserv` по тому самому інтерфейсу `GattClientDevice`, яким користується сам Windows. Перевірено на збірках **26200**, **26220** та **26300**. Майбутні великі оновлення стека Bluetooth у Windows теоретично можуть змінити ці vtable-слоти.
- **Локальний підпис пакета:** Windows вимагає цифрового підпису для встановлення драйверів; `install.ps1` генерує локальний сертифікат лише для вашого ПК та знищує приватний ключ одразу після підписання `winstadia.cat`.
- **Подієва передача через BLE:** контролер Stadia у режимі Bluetooth надсилає HID-звіт лише тоді, коли змінився стан кнопки чи положення стіка. При безперервному русі стіка частота оновлень відповідає інтервалу BLE **7,5 мс (~133 Гц)**.

## Вирішення проблем

- **Контролер не відображається в Studio:** переконайтеся, що Bluetooth увімкнений, перепідключіть геймпад, перевірте перемикач слота XInput (`#1–#4`) або виконайте `.\driver\status.ps1`.
- **Попередження про недоступність `0xE2` або `0xE3`:** у сховищі драйверів Windows усе ще активна старіша версія `winstadia.dll`. Повторно запустіть `install.bat` від імені адміністратора, щоб зібрати й оновити пакет драйвера.
- **Немає вібрації в іграх:** перевірте, що повзунки сили моторів (`Strong/Weak %`) на вкладці **Мотори** виставлені вище `0%`, протестуйте кнопку **Імпульс 1.5с** у Studio та переконайтеся, що вібрація увімкнена в налаштуваннях самої гри.
