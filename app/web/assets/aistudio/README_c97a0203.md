# Stadia Rumble

Небольшой проект для Google Stadia Controller в Windows: драйвер представляет его как Xbox-геймпад, а приложение проверяет, доходит ли команда вибрации.

## Что уже есть

- `driver/` — UMDF-драйвер USB и Bluetooth LE, передающий ввод игры и команды вибрации контроллеру.
- `app/` — простое окно для поиска XInput-геймпада и теста двух моторов.
- `driver/status.ps1` — диагностика подключённого драйвера.

Драйверная часть основана на открытом проекте [aisk/WinStadia](https://github.com/aisk/WinStadia), распространяемом по GPL-3.0. Проект сохраняет эту лицензию и указывает исходную ревизию в [`UPSTREAM_REVISION.txt`](./UPSTREAM_REVISION.txt). Это независимый проект, не связанный с Google или Microsoft.

## Требования

- Windows 11 x64. Bluetooth-режим должен быть включён в контроллере.
- Для сборки приложения — .NET SDK 10.
- Для сборки драйвера — Visual Studio Build Tools 2022 с компонентом **Desktop development with C++**. Скрипт скачивает WDK 10.0.26100 из NuGet.
- Для установки драйвера нужны права администратора.

Драйверная реализация использует внутренний, документированный не полностью интерфейс Windows для BLE GATT. В исходном проекте вибрация проверялась на сборках 26200 и 26220; на сборке 26300 этого проекта она пока не проверена. Обновление Windows может изменить этот интерфейс.

Для снижения нагрузки на BLE частота обновления силы вибрации ограничена четырьмя командами в секунду. BLE-команда ждёт подтверждение до 750 мс; остановка моторов дополнительно повторяется при сбое.
Ожидание между командами вибрации планируется таймером, не занимая рабочий поток драйвера, который обслуживает ввод.

## Быстрый старт

1. Откройте релизный архив в `release\StadiaRumble-1.0.10-win-x64`.
2. Запустите `install.bat` от имени администратора.
3. Подключите Stadia Controller по Bluetooth.
4. Запустите `app\publish\StadiaRumble.exe`.
5. Нажмите **Тест вибрации**.
6. Если контроллер не найден — отключите и подключите его повторно, затем нажмите **Обновить**.

Из корня проекта в исходном дереве можно запустить приложение через SDK:

```powershell
dotnet run --project .\app\StadiaRumble.App.csproj
```

Приложение показывает тест только для XInput-устройств. Сначала нужно собрать и установить драйвер. Само приложение драйвер не устанавливает и не запрашивает права администратора.

## Сборка драйвера

Открой PowerShell в корне проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
& .\driver\build.ps1
```

Пакет появится в `driver\out\pkg`.

Для проверки активной ошибки и результата последней команды вибрации запусти:

```powershell
& .\driver\status.ps1
```

## Установка и удаление

Установка меняет драйвер для Stadia Controller и требует подтверждения UAC. Она также создаёт локальный сертификат подписи пакета. Устанавливай драйвер только после просмотра исходников и на свой риск.

**Установка или удаление через меню:** запусти [`manage.bat`](./manage.bat) в корне проекта и выбери действие. Релизный архив содержит готовый пакет драйвера и не требует Visual Studio Build Tools; в исходном дереве без готового пакета скрипт соберёт драйвер автоматически. Также можно запустить [`install.bat`](./install.bat) для установки или [`uninstall.bat`](./uninstall.bat) для удаления.

Либо через PowerShell:

```powershell
& .\driver\install.ps1
```

Чтобы вернуть штатный драйвер Windows:

```powershell
& .\driver\install.ps1 -Uninstall
```

Подтверди UAC. Если установщик сообщает о необходимости перезагрузки, перезагрузи Windows, затем переподключи контроллер. Запусти приложение и нажми **Тест вибрации**. Если тест работает, но игра не вибрирует, проверь поддержку XInput и настройки вибрации в самой игре.

## Типичные проблемы и решения

- Контроллер не виден в приложении:
  - проверьте, что Bluetooth включён в Win11;
  - подключите контроллер заново;
  - нажмите **Обновить** в приложении;
  - проверьте состояние драйвера через `driver\status.ps1`.
- После установки Windows просит перезагрузку:
  - перезагрузите ПК и снова подключите контроллер.
- Вибрация не приходит после запуска:
  - проверьте, что приложение видит XInput-геймпад;
  - отключите и подключите контроллер повторно;
  - убедитесь, что в игре включена поддержка вибрации.

## Ограничения текущего прототипа

- Приложение проверяет вибрацию; оно не меняет настройки игр и не переназначает кнопки.
- Для сборки драйвера нужны Visual Studio Build Tools с компонентом C++; физическая проверка требует подключённого Stadia Controller.
- Реальную задержку управления и вибрацию нельзя подтвердить только исходным кодом.
